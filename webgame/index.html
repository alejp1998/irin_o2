📖 About this page

🎓 The Project

IRIN O2 — Trabajo Obligatorio 2 (UPM, 2019): an e-puck robot in the Webots simulator whose neural controller (distributed layers, ANN and CTRNN variants) is evolved by a genetic algorithm instead of being hand-programmed. The fitness is the classic Nolfi–Floreano formula from Evolutionary Robotics:

f = V · (1 − √Δv) · (1 − i)
V = wheel speed · Δv = left/right difference (straight driving) · i = max proximity sensor (avoid walls)

🧬 The algorithm

Each genome is the flattened weights of an MLP (8 proximity rays → 4 hidden → 2 wheels). Every generation every robot is evaluated in the arena, then the next population is bred with tournament selection, uniform crossover, gaussian mutation and elitism. Watch the fitness curve climb and the robot start driving in clean straight lines away from the walls.

🖥️ Implementation

The C++ Webots framework (layered controllers, experiment, fitness function) is mirrored here by ga_nn.py (9 unit tests) and its JavaScript port ga-core.js (8 tests) — same NN, same fitness, same GA operators. Source: github.com/alejp1998/irin_o2.
