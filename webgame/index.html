📖 About this page

🎓 The Project

IRIN O2 (UPM, 2019) — a Webots e-puck whose neural controller is evolved by a genetic algorithm instead of learned by gradient descent. The lab evolves layered distributed NN controllers; this page reproduces the pipeline in miniature: an 8-4-2 MLP (proximity rays → hidden → wheel speeds) in a 2D arena, evolved live with the same fitness function.

🧬 Genetic algorithm

Each genome is the weight vector of the controller. The population of \(P\) individuals is evaluated, then a new generation is built by

  • Tournament selection — pick \(k\) genomes at random, keep the fittest, repeat to fill the mating pool;
  • Crossover — recombine two parents' weight vectors;
  • Gaussian mutation — perturb weights with \(\mathcal{N}(0, \sigma^2)\); \(\sigma\) anneals each generation (0.996gen) to refine late in the run;
  • Elitism — the best individuals survive unchanged.

🎯 Fitness (Nolfi & Floreano)

Each genome drives the robot for 120 steps; the per-step fitness rewards fast, straight, obstacle-avoiding motion:

\[ f = V\,(1 - \sqrt{\Delta v})\,(1 - i) \]

where \(V\) is the translational speed, \(\Delta v\) the rotational difference between wheels (penalizing turns) and \(i \in [0,1]\) the strongest proximity reading (penalizing walls). The chart plots the best fitness per generation; with the default settings the population reaches the task ceiling (\(f \approx 0.53\)) within ~100 generations.

🧪 How to use

Press ▶ Evolve — the button becomes ⏸ Pause while the GA runs. The arena shows the best individual so far driving with its proximity rays; the fitness curve climbs as the population improves. Adjust population size, mutation \(\sigma\) and speed; ↻ Reset starts a fresh run with a new random seed.
